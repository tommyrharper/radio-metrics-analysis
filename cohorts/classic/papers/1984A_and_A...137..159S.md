# Enhancements to the deconvolution algorithm "CLEAN"

**Bibcode:** 1984A&A...137..159S
**Authors:** D. G. Steer, P. E. Dewdney, and M. R. Ito
**ADS:** https://ui.adsabs.harvard.edu/abs/1984A%26A...137..159S/abstract
**Full text:** https://articles.adsabs.harvard.edu/pdf/1984A%26A...137..159S

## One-line summary
Steer, Dewdney, and Ito modify CLEAN to select and subtract threshold-defined groups of components, recomputing each residual from the original dirty map, which suppresses corrugation artifacts on extended emission, reduces accumulated finite-precision error, and can require far fewer iterations than point-by-point CLEAN.

## Method
The paper identifies two linked weaknesses of standard Högbom CLEAN on extended emission. Subtracting a shifted dirty beam at one residual peak impresses the beam's adjacent samples and sidelobes onto a smooth feature, so later peak searches select a regularly separated set of components that becomes stripes or corrugations in the reconstruction. Repeated incremental subtraction can also accumulate truncation error when many iterations are performed with limited-precision arithmetic.

The modified method, now commonly called Steer-Dewdney-Ito or SDI CLEAN, replaces single-pixel selection with a trim-contour operation. At each iteration it finds the residual peak and retains every residual pixel above a selected fraction \(T_c\) of that peak. This can select several disconnected islands when multiple features have comparable brightness. Because a component embedded in a group is scaled approximately by the dirty-beam volume rather than only by its normalized peak, the selected group is convolved with the dirty beam and scaled so that the convolved group's peak equals the loop gain times the current residual peak. The scaled group is added to the accumulated density file.

The complete accumulated density file is then convolved with the dirty beam by FFT and subtracted from the original dirty map, rather than subtracting each new component incrementally from the preceding residual. This ordering reduces the accumulation of finite-precision subtraction error. The authors note that the subtraction could instead be performed in the Fourier domain from gridded visibility data.

For fields containing both point and extended sources, the algorithm tests whether the selected group's peak and its peak after dirty-beam convolution occur at different locations. When they differ, it treats the brightest selected pixel as a point source and raises that pixel's effective gain to the specified full loop gain; the gain never exceeds the user setting. This prevents compact sources from converging much more slowly than extended components.

The recommended trim contour is slightly above the largest non-central value of the dirty beam, even when that value is an adjacent sample on an oversampled main lobe rather than a conventional sidelobe. A trim contour that is too high approaches standard CLEAN, while one that is too low can admit sidelobes as nearly irrecoverable false components. For extended sources, the recommended loop gain is slightly below \(1-T_c\). The authors argue that the trim contour can be derived automatically from the beam, leaving only the stopping criterion for the user.

## Performance / fidelity metrics used
- **No standardized scalar fidelity benchmark or measured hardware performance is reported.** The paper provides synthetic contour-map comparisons, iteration counts, one unreported numerical RMS comparison, and analytical operation-count models. It does not report PSNR, SNR improvement, dynamic range, recovered-flux error, astrometric error, wall-clock time, memory, throughput, or computing hardware.
- **Noise-free 64 x 64 synthetic test:** the positive test object has a lowest plotted contour at about 1% of its highest contour. Its dirty beam comes from an untapered circular aperture whose diameter is about two-thirds of the full rectangular aperture extent, with a 40-degree sector removed to simulate an unsampled observing interval and the central DC term retained. The largest positive non-central beam sample is 56% of the peak and the largest negative sidelobe is 38%. Modified CLEAN uses \(T_c=0.55\) and 17 iterations. A comparison CLEAN with a 15% central beam spike uses 2,000 subtractions. Both density files are visually free of stripes and are described as comparable, while the modified result has lower RMS error against the original object; the paper gives no RMS values. Standard CLEAN leaves visibly separated components in the extended regions. The figures compare unconvolved density files so that clean-beam smoothing does not hide differences between deconvolution algorithms.
- **Noisy 256 x 256 synthetic test:** the object combines point sources with extended emission; the paper displays only its central 64 x 64 region. The dirty map uses a circular sinc-function beam with noise whose standard deviation is 1% of the peak, and the lowest displayed contour is 3% of the peak. The modified density file visually reproduces both the compact and extended structure, whereas standard CLEAN reproduces the narrow sources but the authors judge the extended area to be very poorly reproduced. No iteration count or scalar error is given for this test.
- **Finite-precision error analysis:** for a dirty-beam sidelobe at 1% of the peak, loop gain 0.1, and arithmetic with five significant figures, the paper states that each subtraction loses one significant figure of the beam. Because truncation proceeds in the same direction, after about \(10^3\) subtractions the accumulated error can be as large as the sidelobe. This is an illustrative numerical analysis, not a measured machine experiment; no hardware or arithmetic implementation is named.
- **Analytical work estimates:** for an image with \(M\) pixels, the paper approximates standard CLEAN work as \(N_s \approx 2Q_sM\), where \(Q_s\) is its iteration count. Modified CLEAN is estimated as \(N_m \approx Q_mM(4\log(M)/2+4)\), comprising four FFTs plus density-file addition, complex multiplication, trimming, and subtraction per iteration. A corresponding Clark CLEAN expression includes major-cycle count, minor-cycle count, and beam-patch area. The authors derive iteration-count expressions showing that modified CLEAN becomes relatively more favorable as the source covers more beam areas or a larger fraction of the image. These are algorithmic operation models, not timings, and the logarithm base and FFT constants depend on implementation details.
- **Limitations and qualitative criteria:** the method assumes that the shape of an extended dirty-image feature is an adequate first estimate of its component group, with errors corrected later. A low trim contour can permanently select sidelobes as source components. Mixed compact and extended fields require the added point-source test. As with other deconvolution methods, filling unsampled Fourier coverage requires prior assumptions; the modified method relaxes standard CLEAN's implicit preference for the narrowest possible feature but does not recover information from measurements that were never made.

## Relevance to visibility→gridding→iFFT→deconvolution ML pipeline
This paper is a direct classical baseline for the deconvolution stage after gridding and inverse Fourier transformation. It starts from the dirty image, explicitly defined as the Fourier transform of observed visibilities, and the dirty beam, then changes how image-plane residual structure is converted into model components. Its thresholded group selection resembles a hand-designed region proposal or adaptive support mask, while its beam-aware scaling and full-model residual recomputation resemble model-based consistency steps that can be unrolled or learned.

For an ML pipeline, SDI CLEAN supplies concrete failure cases and evaluation contexts: extended-source corrugation, mixed point and diffuse emission, finite-precision drift, missing Fourier coverage, and sensitivity to PSF sidelobes and oversampling. It also shows why visual smoothness alone is insufficient: both striped and smooth reconstructions can agree with sampled visibilities, so a learned system should report image-domain fidelity, residual visibility consistency, flux recovery, and robustness across sampling patterns. The paper's operation-count analysis and 17-versus-2,000 iteration example offer computational baselines, but its lack of wall-clock hardware measurements and quantitative values for the reported RMS improvement prevents direct throughput or fidelity comparison with modern ML methods.
