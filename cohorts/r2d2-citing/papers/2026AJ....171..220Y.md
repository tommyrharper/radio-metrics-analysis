# An Imaging Algorithm Based on Generalized Minimax-concave Penalty in Radio Interferometry

**Bibcode:** 2026AJ....171..220Y
**Authors:** Xiaocheng Yang, Gaofeng Wu, Lin Wu, Jingye Yan, Xuning Lv, Yang Yang, Li Deng, Bo Wei
**ADS:** https://ui.adsabs.harvard.edu/abs/2026AJ....171..220Y/abstract
**arXiv:** not found (no arXiv preprint listed on ADS; article is open access on IOPscience, DOI: 10.3847/1538-3881/ae45a1)

## One-line summary
The paper proposes GMCP (Generalized Minimax-Concave Penalty), a nonconvex sparse-regularization imaging algorithm for radio interferometry that stays provably convex overall, solved via forward-backward splitting (FBS) with an adaptively estimated regularization parameter, and benchmarks it against CLEAN/MS-CLEAN, SARA, AIRI, R2D2, and their own earlier LPG method on VLA and DAocheng Radio Telescope (DART) data.

## Method
GMCP replaces the biased L1/reweighted-L1 sparsity penalty used in compressed-sensing RI imaging with a piecewise-concave penalty (generalizing the scalar minimax-concave penalty, MCP) that more closely approximates the ideal but NP-hard L0-norm, while a scaling-matrix condition (tied to the nonconvex control parameter γ, typically 0.5–0.8) keeps the overall least-squares + penalty objective convex, guaranteeing a global optimum. The resulting problem is recast as a convex–concave saddle-point problem and solved with the forward-backward splitting (FBS) algorithm; the regularization parameter λ is updated at each iteration via a maximum-likelihood estimator rather than fixed by hand. Per-iteration computational complexity is shown to be lower than SARA (preconditioned primal-dual) and slightly higher than the authors' earlier LPG (Lq-norm proximal gradient) method.

## Performance / fidelity metrics used
- **SNR (dB):** SNR = 20·log10(‖x‖₂ / ‖x − x̂‖₂), the primary reconstruction-fidelity metric (x = ground truth, x̂ = reconstruction).
- **SNRlog (dB):** a "log-scale" SNR variant (following Thouvenin et al. 2023) intended to give a robust measure of reconstruction quality specifically for faint emission, computed on a log-stretched image using an estimated noise level ε and unit vector I_N.
- **Image-domain data fidelity σ:** defined via the estimated residual dirty image r relative to the dirty image x_d (following Aghabiglou et al. 2024's R2D2 fidelity metric); lower is better.
- **Computation time (s):** wall-clock runtime, all methods run on the same MATLAB R2021a / Intel i9-13900HX / 64GB RAM setup (AIRI and R2D2 GPU-accelerated on an RTX 4060 8GB).
- **VLA/3c353 experiment (Table 1, avg. of 100 sims, iSNR=35dB):** SARA 24.38dB SNR/8.06dB SNRlog/σ=4.858e-2/113.0s; AIRI 26.84/14.12/4.740e-2/55.2s; LPG 28.16/14.95/4.206e-2/64.5s; **R2D2 28.33/15.36/3.919e-2/5.3s**; **GMCP 28.82/16.19/3.054e-2/69.1s (best SNR/SNRlog/fidelity, but slower than AIRI/LPG/R2D2)**.
- **DART/Sun experiment (Table 2, avg. of 100 sims, iSNR=35dB):** MS-CLEAN 10.18dB SNR/3.21dB SNRlog/σ=28.70e-2/7.5s; SARA 28.89/12.39/3.549e-2/24.3s; LPG 31.39/13.56/2.293e-2/18.8s; **GMCP 32.47/14.16/1.756e-2/20.2s (best on all fidelity metrics; R2D2 not tested here)**.
- **Ablation/sensitivity studies:** γ sweep (Fig. 5) shows non-monotonic behavior for γ∈[0,0.5] then monotonic quality decline for γ∈[0.5,1], justifying γ=0.5 as default; fixed vs. adaptive λ (Fig. 6) shows the adaptive MLE-based λ gives higher SNR/SNRlog and lower σ than a fixed λ=1e-5; convergence plot (Fig. 7) shows the objective function decreasing quickly and stabilizing; noise-robustness sweep (Fig. 8) shows GMCP clearly beats SARA and slightly beats AIRI/LPG/R2D2 across input noise levels.
- **Qualitative comparison to R2D2 (VLA case):** R2D2 better preserves extended diffuse/faint emission with smoother low-intensity transitions; GMCP achieves sharper recovery in high-intensity compact regions but with mild staircasing and some suppression of faint/low-level emission — described as a trade-off rather than a strict win for either method, even though GMCP's aggregate SNR/SNRlog/σ numbers are marginally higher than R2D2's.

## Relevance to visibility→gridding→iFFT→deconvolution ML pipeline
This is a non-ML (convex/nonconvex optimization) competitor/baseline to R2D2 and AIRI rather than an ML method itself, but it directly benchmarks against R2D2 using R2D2's own fidelity metrics (SNR, SNRlog, image-domain data fidelity σ) and measurement operator setup, making it a useful reference point for how much headroom classical sparse-regularization deconvolution still has versus learned residual-DNN deconvolution, especially the noted trade-off between GMCP's sharper compact-source recovery and R2D2's better diffuse/faint-emission preservation.
