# Generative imaging for radio interferometry with fast uncertainty quantification

**Bibcode:** 2025arXiv250721270M
**Authors:** Matthijs Mars, Tobías I. Liaudat, Jessica J. Whitney, Marta M. Betcke, Jason D. McEwen
**ADS:** https://ui.adsabs.harvard.edu/abs/2025arXiv250721270M/abstract
**arXiv:** https://arxiv.org/abs/2507.21270

## One-line summary
The paper introduces RI-GAN, a regularised conditional Wasserstein-GAN with a measurement-operator-embedded "gradient U-Net" (GU-Net) generator, that produces radio-interferometric image reconstructions together with fast, sample-based uncertainty maps by generating many posterior samples cheaply on GPU, avoiding the cost of MCMC.

## Method
RI-GAN is a conditional generative adversarial network for radio-interferometric imaging that takes the dirty image and point spread function (PSF) as conditioning inputs and learns to sample from an approximate image posterior. The generator is a U-Net variant — a "gradient U-Net" (GU-Net) — that explicitly embeds the measurement operator (i.e. the gridding/degridding + FFT data model) inside the network via a data-fidelity gradient step, rather than relying purely on a black-box CNN; this is compared against a standard U-Net generator without the embedded operator. Training uses a regularised conditional Wasserstein GAN (rcGAN-style) objective designed to prevent mode collapse, so that repeated draws from the trained generator (conditioned on the same dirty image/PSF) form a set of diverse posterior samples. Per-pixel uncertainty is then estimated as the standard deviation across many generated samples (32 used in the main experiments). Training was performed on simulated galaxy images using 4 NVIDIA A100 (80GB) GPUs, effective batch size 16, taking about 48 hours; because only one evaluation of the measurement operator is needed per observation and sampling is done via feed-forward network passes (parallelisable across GPUs), inference/sample generation is very fast compared to iterative sampling schemes such as MCMC.

## Performance / fidelity metrics used
- **SNR (signal-to-noise ratio, dB):** SNR(x_true, x_pred) = 20·log₁₀(‖x_true‖₂ / ‖x_true − x_pred‖₂), the primary reconstruction-fidelity metric used throughout. No PSNR or SSIM metrics were reported in the extracted results.
- **In-distribution test set (galaxy images):** GU-Net RI-GAN gives a consistent, non-overfitting SNR improvement over both the dirty image and the plain U-Net RI-GAN variant; SNR distributions across training and test sets are shown as boxplots (Fig. 3), with GU-Net performing similarly on train and test (indicating no overfitting) and the U-Net variant performing worse.
- **Out-of-distribution test (30 Doradus, dynamic range ~600):** used as a generalisation stress test. Reported SNR values: **GU-Net RI-GAN: 46.03 dB**, **U-Net RI-GAN: 30.80 dB**, **CLEAN: 32.55 dB**. I.e. the GU-Net variant (with the measurement operator embedded in the generator) outperforms both the plain U-Net RI-GAN and CLEAN by a wide margin out-of-distribution, while the plain U-Net without the embedded operator performs comparably to or worse than CLEAN — attributed to explicit inclusion of the measurement operator improving generalisation.
- **Uncertainty-error correlation (proxy for UQ calibration):** Pearson correlation coefficient between the per-pixel predicted uncertainty (std across samples) and the per-pixel absolute reconstruction error |x_true − x_pred|. With 32 posterior samples: **GU-Net: r = 0.69**, **U-Net: r = 0.58**, showing the GU-Net's uncertainty maps track true error better.
- **Number-of-samples ablation:** both SNR and the uncertainty–error correlation improve as the number of posterior samples increases and plateau around 32 samples; low sample counts giving markedly lower SNR/correlation is interpreted as evidence of genuine sample diversity (i.e. no mode collapse).
- **Calibration/coverage of credible intervals:** not yet quantitatively validated in this paper — the authors explicitly flag as future work the need for "a more in-depth analysis of the statistical significance of the uncertainties," including coverage-probability estimation, to verify the generated samples follow the true posterior.
- **Compute cost / runtime vs. sampling-based UQ (e.g. MCMC):** no wall-clock numbers are given directly, but the paper emphasises the architecture requires only a single evaluation of the measurement operator per observation, and that posterior samples "can be generated in parallel on one or a few GPUs, which makes the generation of samples for a single observation very fast" — a qualitative but central claim of large speed advantage over iterative/sampling-based UQ approaches like MCMC. No direct quantitative comparison to R2D2/AIRI-family or diffusion-based imaging methods was found in the extracted text; the only explicit numerical baseline comparison is against CLEAN.

## Relevance to visibility→gridding→iFFT→deconvolution ML pipeline
RI-GAN is directly relevant as an end-to-end learned alternative to the deconvolution step: its GU-Net generator embeds the measurement operator (gridding/degridding + FFT) inside the network architecture itself, which the OOD (30 Doradus) result suggests is key to generalising beyond training data and dynamic range; and its GAN-sampling approach shows that fast, GPU-parallel, feed-forward posterior sampling can deliver informative per-pixel uncertainty maps essentially "for free" compared to MCMC, which is valuable evidence for adding fast, calibrated uncertainty quantification to an ML-based deconvolution stage in the pipeline.
