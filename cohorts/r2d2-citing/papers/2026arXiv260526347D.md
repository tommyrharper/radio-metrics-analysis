# A distributed resource-adaptive implementation of the widefield radio-interferometric measurement model for scalable image formation

**Bibcode:** 2026arXiv260526347D
**Authors:** Arwa Dabbech, Yves Wiaux
**ADS:** https://ui.adsabs.harvard.edu/abs/2026arXiv260526347D/abstract
**arXiv:** https://arxiv.org/abs/2605.26347

## One-line summary
Presents a distributed, resource-adaptive implementation of the widefield radio-interferometric measurement operator Φ (and Φ†Φ), using an automated hybrid w-stacking/w-projection scheme and memory-controlled Fourier partitioning to make the measurement model scalable to large data volumes under fixed compute/memory budgets.

## Method
The measurement operator Φ (and its adjoint) models the mapping from sky image to visibilities via a non-uniform Fourier transform (NUFFT); for widefield imaging the line-of-sight w-component makes the effective PSF position-dependent and the model far more expensive than the 2D NUFFT case. The authors decompose Φ into low-dimensional operators specific to w-bins via a hybrid w-stacking/w-projection approach, where the number of w-bins is chosen automatically to minimize computational cost subject to the compute system's memory constraints. Residual w-offsets within each bin are absorbed as measurement-specific Fourier (w-projection) kernels augmenting the sparse de-gridding matrix G of the basic NUFFT model, with kernels compressed via hard-thresholding on an ℓ2-energy criterion. An optional data-dimensionality-reduction step jointly encodes the sequential de-gridding/gridding operations of Φ†Φ into a holographic matrix H when memory is tight. For further parallelization, the sparse G or H matrices are decomposed into blocks via memory-controlled Fourier partitioning and distributed across CPU workers/nodes. A MATLAB implementation is released in BASPLib and plugged into existing iterative imagers (uSARA, AIRI, Hyper-uSARA, HyperAIRI). Validation uses real MeerKAT and ASKAP data (monochromatic and wideband) plus a dedicated computational-efficiency analysis on simulated MeerKAT data (Cirrus HPC, up to 10 nodes × 36 cores/256 GB).

## Performance / fidelity metrics used
- **Memory footprint of measurement matrices** — explicit byte-cost formula for the de-gridding matrix, m_G(P) = 24K(P) + 4N′ bytes (K = non-zero elements, N′ = oversampled Fourier-space size), with an asymptotic regime m_G* ≈ 24MQ (M = number of measurements, Q = interpolation kernel support). Using the holographic-matrix (H) formulation instead of G gives a reported **7-fold reduction in memory** to store the operator, at roughly **30% higher precomputation cost**.
- **Precomputation vs. application cost amortization** — the one-off cost to build the operator matrix is matched by its application cost within "tens of iterations," and is exceeded by roughly an order of magnitude within a few hundred iterations of an iterative imaging algorithm — used as the basis for automatically choosing between precomputed and on-the-fly evaluation strategies.
- **Number of w-layers / bins required (vs. WSClean baseline)** — used as a proxy for computational efficiency: e.g., 23 w-layers found optimal for a 10-node test configuration vs. WSClean's recommended 126 for pure w-stacking; 14 w-layers used for MeerKAT ESO 137-006 imaging (4096×4096 px, 1.91°) vs. WSClean's 40; 12 w-layers per frequency for an ASKAP field (4096×4096×8) vs. WSClean's 48–73. Fewer layers at comparable/better efficiency is the headline efficiency claim.
- **Runtime breakdown by operation (Figure 8)** — FFT computations dominate total application runtime; de-gridding/gridding matrix-vector products are "almost negligible" by comparison; total application time grows with the number of w-layers (e.g., 23 → 126 layers).
- **Distributed/parallel scaling** — tested from 1 to 10 CPU nodes; the planning stage adapts the number of workers to available CPU cores (e.g., a 3-node run needing 122 workers but only 108 cores available triggers a switch to on-the-fly computation); inter-worker communication overhead (image-sized variable exchange with FFT workers, Fourier-coefficient exchange with de-gridding/gridding workers) is tracked as part of total cost.
- **Overall computational cost relative to CLEAN** — for the MeerKAT ESO 137-006 case, the proposed high-precision measurement operator achieves imaging cost "within one order of magnitude of CLEAN," used as the headline scalability/cost comparison against the standard (non-ML) imaging pipeline.
- **No explicit numerical-accuracy benchmark** — the paper does **not** report direct error/SNR metrics comparing the approximate (w-stacking/w-projection) operator against an exact reference operator. Fidelity is instead argued indirectly: downstream images from uSARA/AIRI/HyperAIRI using this operator are asserted to match or exceed WSClean-based imaging quality, but the paper explicitly states it "does not address the performance of the framework in image formation in terms of imaging quality," deferring quantitative dynamic-range/SNR validation to prior BASP-group publications.

## Relevance to visibility→gridding→iFFT→deconvolution ML pipeline
Directly relevant: this paper is entirely about making the measurement operator (degridding/gridding + w-correction, i.e., the visibility↔grid stage feeding the iFFT) scalable and memory/compute-adaptive for large widefield/wideband data, which is the operator repeatedly called inside iterative and ML-based deconvolution/imaging algorithms (uSARA, AIRI) — but it does not itself report image-fidelity (SNR/dynamic-range) benchmarks, leaving that validation to companion papers.
