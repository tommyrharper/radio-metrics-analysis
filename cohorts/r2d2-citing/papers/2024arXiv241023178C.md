# Uncertainty Quantification for Fast Reconstruction Methods Using Augmented Equivariant Bootstrap: Application to Radio Interferometry

**Bibcode:** 2024arXiv241023178C
**Authors:** Mostafa Cherif, Tobías I. Liaudat, Jonathan Kern, Christophe Kervazo, Jérôme Bobin
**ADS:** https://ui.adsabs.harvard.edu/abs/2024arXiv241023178C/abstract
**arXiv:** https://arxiv.org/abs/2410.23178 (arXiv:2410.23178; accepted at the ML and the Physical Sciences Workshop, NeurIPS 2024)

## One-line summary
The authors propose CARB (Conformalized Augmented Radio Bootstrap), an unsupervised, radio-interferometry-specific equivariant bootstrapping method with conformal calibration, that produces fast, statistically-valid pixel-wise uncertainty maps for reconstructions from an ultra-fast unrolled deep network (EVIL-Deconv), outperforming standard/equivariant bootstrap and (conformalized) quantile regression baselines.

## Method
Reconstructions come from EVIL-Deconv, an unrolled-optimization network (LISTA-CP-style, 10 unrolled proximal-gradient layers with a pretrained DRUNET denoiser) trained on simulated MeerKAT PSFs across a 30–60 dB SNR range (40 dB used in experiments), applied to 64×64 patches derived from Hubble Space Telescope images as ground truth. To quantify uncertainty without retraining or costly sampling, they build on equivariant bootstrapping (Pereyra & Tachella 2024): bootstrap measurements are generated by applying a random invertible group action to the current estimate before re-observing/re-reconstructing, so the induced forward operator has a different null space and better probes reconstruction variability than a standard (non-equivariant) parametric bootstrap. CARB augments this with RI-specific group actions — small circular shifts (≤2 px), flips, 90° rotations, plus novel invertible low-/high-shelving frequency filters calibrated to the PSF — combined into random compositions, using 500 bootstrap samples per image. The resulting empirical quantile-based confidence intervals are then conformalized via Risk-Controlling Prediction Sets (RCPS, Angelopoulos et al. 2022) to give distribution-free statistical coverage guarantees (target error rate δ = 0.1), calibrated on 1000 held-out images. Evaluated against parametric bootstrap, plain equivariant bootstrap, quantile regression, and conformalized quantile regression (CQR) on 10,000 test images.

## Performance / fidelity metrics used
- **Reconstruction fidelity metrics (Appendix A.2, for the base EVIL-Deconv network vs. CLEAN and a Plug-and-Play/DnCNN baseline)**: Normalized Mean Squared Error, NMSE [-dB] = −20·log10(‖x⋆−x̂‖₂/‖x⋆‖₂), and Structural Similarity Index Measure (SSIM), plus mean reconstruction time. Reported (Table 2, median values): CLEAN — NMSE 4.2 dB, SSIM 0.296, 794 ms; PnP (DnCNN) — NMSE 16.3 dB, SSIM 0.869, 1110 ms; EVIL-Deconv (used for all UQ experiments) — NMSE 19.9 dB, SSIM 0.970, 51 ms.
- **UQ interval tightness — average ℓ2 norm ratio**: mean ratio of the 90% confidence-interval length to the ground-truth image ℓ2 norm (Table 1). Values: Quantile Regression 0.15; Conformalized QR 204.08 (drastically inflated, impractical); Parametric Bootstrap 0.07; Equivariant Bootstrap 0.13; Augmented Radio Bootstrap (uncalibrated CARB) 0.29; CARB (conformalized) 0.34.
- **Empirical coverage**: fraction of pixels whose true residual falls within the estimated interval, Ey{P(Î⁻α(y) < x⋆−x̂(y) < Î⁺α(y))}, with target ≥1−δ = 90% (α=δ=0.1). Reported (Table 1): Quantile Regression 14%; Conformalized QR 92% (valid but over-wide, uninformative); Parametric Bootstrap 0% (severely underestimates uncertainty); Equivariant Bootstrap 7% (also underestimates); Augmented Radio Bootstrap 87%; CARB 91% (best trade-off of tight intervals + correct coverage).
- **Coverage plots** (Fig. 4): empirical coverage vs. confidence level curves (following Pereyra & Tachella 2024) using the pivotal statistic ‖x⋆−x̂(Y)‖²₂, comparing parametric bootstrap and equivariant bootstrap variants with increasing group-action richness (rotations → +flips → +1/2/3-px shifts → full Augmented Radio Bootstrap); the Augmented Radio Bootstrap tracks the ideal diagonal closely (slightly conservative underestimate).
- **Runtime comparison**: ~735 ms per image to construct confidence regions for all bootstrap-based methods (500 samples, parallelized 128 at a time) vs. ~153 ms for direct quantile-regression inference — bootstrap is slower but still fast and highly parallelizable since each sample is independent given x̂(y).
- **Ablation**: number of bootstrap samples (500) chosen via convergence of the average variation of pixel-wise 90th-quantile uncertainty norms with sample count (Appendix D, Fig. 6).

## Relevance to visibility→gridding→iFFT→deconvolution ML pipeline
Directly relevant to the deconvolution/reconstruction stage: it takes reconstructions from an ultra-fast unrolled deep network operating on gridded/back-projected data and adds cheap, statistically-calibrated pixel-wise uncertainty quantification (via bootstrapping + conformal prediction) without retraining — a practical template for adding trustworthy UQ to any fast ML-based deconvolution step in the pipeline, complementary to fidelity metrics like NMSE/SSIM used to benchmark the underlying reconstruction network.
