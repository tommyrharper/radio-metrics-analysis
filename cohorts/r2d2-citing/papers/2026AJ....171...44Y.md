# A Radio-interferometric Imaging Method Based on Adaptively Learned Sparsifying Basis

**Bibcode:** 2026AJ....171...44Y
**Authors:** Xiaocheng Yang, Yixin Zhang, Lin Wu, Jingye Yan, Mingfeng Jiang, Haixiang Zhang, Xuning Lv, Yang Yang, Li Deng
**ADS:** https://ui.adsabs.harvard.edu/abs/2026AJ....171...44Y/abstract
**arXiv:** not found (no arXiv preprint indexed; article is Gold OA (CC-BY) on IOPscience, DOI: 10.3847/1538-3881/ae22d7; code at Zenodo DOI:10.5281/zenodo.17539414)

## One-line summary
The paper proposes ALSB (Adaptively Learned Sparsifying Basis), a compressed-sensing radio-interferometric imaging algorithm that replaces fixed sparsifying bases (wavelets, etc.) with a dictionary learned adaptively from overlapped image patches, solved via split Bregman iteration, and benchmarks it against MS-CLEAN, SARA, AIRI, and the authors' own earlier wavelet-tight-frame (WTF) method.

## Method
The forward model is y = ΦDα + n, where Φ = GFZ is the measurement operator (gridding G, FFT F, weighting Z) mapping image to visibilities. Instead of a single fixed basis over the whole image, ALSB learns a patch-level dictionary D via K-SVD, sparsely representing overlapped image patches (via OMP) to capture local/non-stationary structure and reduce blocking artifacts. The ℓ0-regularized objective is split via split Bregman iteration into an image-update subproblem (gradient descent) and a sparse-coding/dictionary-learning subproblem, alternating between the two. Per-iteration complexity is O(mN log(mN) + M·ℬ_k + nKL·ℬ_s). Experiments use K=256 dictionary atoms, sparsity level L=4, and 8×8 (patch size sensitivity tested, optimum near 64×64 in one sweep).

## Performance / fidelity metrics used
- **SNR (dB):** SNR = 20·log10(‖x‖₂ / ‖x − x̃‖₂), ground truth vs. reconstructed image — primary reconstruction-quality metric.
- **Image-domain data fidelity σ:** based on the estimated residual dirty image r relative to the dirty image x_d (same style of fidelity metric as used by R2D2/AIRI papers); lower is better.
- **Wall-clock runtime (s).**
- **VLA/W28 supernova remnant (Table 1, 1024×1024, 894,240 baselines, iSNR=35dB):** SARA 33.51dB SNR / fidelity 0.0182 / 494s; AIRI 34.62 / 0.0106 / 285s; WTF 35.73 / 0.0085 / 297s; **ALSB 36.39 / 0.0067 / 301s (best SNR and fidelity, runtime comparable to AIRI/WTF, much faster than SARA).**
- **SKA/3C353 radio galaxy (Table 2, 512×512, 578,358 baselines, iSNR=35dB):** SARA 30.68 / 0.0205 / 297s; AIRI 32.14 / 0.0162 / 192s; WTF 33.25 / 0.0123 / 205s; **ALSB 33.97 / 0.0103 / 210s (best SNR/fidelity again).**
- **DART real solar data (Table 3, 256×256, 86,143 baselines, 294 antennas, 425 MHz, iSNR=40dB):** MS-CLEAN 10.77 / 0.28025 / 10.14s; SARA 29.48 / 0.03113 / 32.82s; WTF 33.54 / 0.00676 / 18.73s; **ALSB 33.93 / 0.00281 / 20.85s (best SNR/fidelity; MS-CLEAN far behind all CS/learned methods, ALSB gives roughly 2.4x lower fidelity residual than WTF and ~11x lower than SARA).**
- **Sensitivity/robustness:** parameter sweeps over patch size and sparsity level L (optimum L=4); convergence reached by ~iteration 15 across noise levels; noise-robustness test shows ALSB consistently outperforms SARA, AIRI, and WTF across input SNR levels, with the authors noting best restoration of bright/compact sources and smallest internal structure errors.
- PSNR and SSIM are not used/discussed in this paper.

## Relevance to visibility→gridding→iFFT→deconvolution ML pipeline
ALSB is a non-deep-learning, dictionary-learning/compressed-sensing competitor benchmarked directly against the learned-regularization method AIRI (and implicitly the R2D2 family via shared SNR/fidelity metrics and measurement-operator setup), showing that adaptive sparse dictionaries can match or beat AIRI's fidelity/SNR at comparable runtime — useful as a non-DNN baseline for how much the deconvolution step in a learned pipeline actually gains from full neural-network regularizers versus lighter adaptive-dictionary sparsity priors.
